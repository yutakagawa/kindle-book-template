# KDP 登録情報の下書き（内容紹介・キーワード・カテゴリー）

KDP で本を登録するとき、「電子書籍の詳細」（ペーパーバックなら「ペーパーバックの詳細」）で次の 3 つを入力します。

- **内容紹介**: Amazon の商品ページに出る本の説明
- **キーワード**: 検索で本を見つけてもらうための語（7 つまで）
- **カテゴリー**: Amazon のストアでどの分類に並べるか（3 つまで）

`scripts/kdp-listing.py` は、`book.yaml` と原稿（`chapters`）から、この 3 つの**下書き**を Markdown のファイルに書き出します。KDP の文字数などの制限を超えていないか、ガイドラインで禁止されている表現が入っていないかも確認します。

> **これは下書きです。** 内容紹介の文章やキーワードの選び方は、本の売れ行きに直接かかわります。出力をそのまま貼り付けず、必ず読み直して自分の言葉で手直ししてください。

## 使い方

必要なのは Python 3 と PyYAML だけです（EPUB のビルドと同じ。`pip install -r requirements.txt`）。Pandoc や EPUBCheck は使いません。

```bash
# 1 冊分 → dist/my-book-kdp-listing.md
python3 scripts/kdp-listing.py books/my-book

# books/ 以下の全ての本
python3 scripts/kdp-listing.py --all
make listing                                   # 同じ（make が使える環境）
make listing-book BOOK=books/my-book           # 1 冊だけ

# JSON も書き出す（dist/my-book-kdp-listing.json。ほかのツールで使うとき）
python3 scripts/kdp-listing.py books/my-book --json

# ファイルを作らず、画面に出す
python3 scripts/kdp-listing.py books/my-book --stdout

# KDP の制限を超えた項目があれば失敗（終了コード 1）にする。CI などで使う
python3 scripts/kdp-listing.py --all --strict
```

| オプション | 意味 |
|---|---|
| `--all` | `books/*/book.yaml` がある全ての本 |
| `-o DIR` / `--output-dir DIR` | 出力先（既定: `dist/`） |
| `--json` | Markdown に加えて JSON も書き出す |
| `--stdout` | ファイルを作らず、Markdown を標準出力に出す |
| `--strict` | 内容紹介の文字数・キーワードの文字数や個数・カテゴリーの個数が KDP の上限を超えている、または使えない HTML タグや見えない文字がある場合に終了コード 1 にする |

実行すると、ファイルの場所と概要、確認が必要なことが表示されます。

```text
[kdp-listing] dist/vertical-sample-kdp-listing.md
[kdp-listing]   内容紹介 484/4000 文字・キーワード 7/7 個・カテゴリー 3/3 個
```

## 出力の見方

`dist/<本のディレクトリ名>-kdp-listing.md` には、次の順で書かれます。

1. **確認が必要なこと** … 上限を超えた項目や、禁止されている表現の疑いがある箇所（何もなければこの節は出ません）
2. **内容紹介** … HTML 版（KDP の入力欄にそのまま貼れる）と、読み直し用のプレーンテキスト版。HTML タグを含めた文字数も表示します
3. **キーワード（7 つ）** … 1 欄ずつの表。どこから取った語か（`book.yaml` か原稿か）と文字数を表示します。表の下に入れ替え用の「その他の候補」も出ます
4. **カテゴリーの候補（3 つまで）** … 推定した分類と、その根拠になった語。表の下に「ほかの候補」も出ます

## 下書きの作り方

### 内容紹介

次の順でつなげ、`<p>` `<h4>` `<ul>` `<li>` `<br>` だけを使った HTML にします。

1. **書き出し**: `book.yaml` の `kdp.description`、なければ `description`
2. **読者への語りかけ**: 「はじめに」「まえがき」など、章番号を付けない最初の章（`{.unnumbered}`）の冒頭の数文（既定で 300 文字まで）。インラインコード（`` `…` ``）を含む文は、コードを除くと意味が通らなくなるので使いません
3. **本書の内容**: 章番号の付く章と付録の見出し（`#`）と、その下の節の見出し（`##`）の一覧
4. **締めくくり**: `book.yaml` の `kdp.closing`（書いた場合だけ）

HTML タグを含めて 4,000 文字を超える場合は、まず節の見出しを省き、それでも収まらなければ後ろの章から省いて「ほか」とします。`<` `>` `&` は KDP の指定どおり `&lt;` `&gt;` `&amp;` に置き換えます。ルビ（`{漢字|かんじ}`）は親文字だけ、強調やリンクは文字だけを残し、コードブロック・画像・脚注・相互参照は除きます。

### キーワード

1. `book.yaml` に `kdp.keywords` があれば、それをそのまま使います（原稿からは選びません）
2. なければ `book.yaml` の `keywords` を先に入れ、残りの欄を原稿から抽出した語で埋めます

原稿からの抽出では、カタカナ語（3 文字以上）、英単語、漢字の複合語（2〜6 文字。送りがなが続くものは除く）を数え、見出しやタイトル・説明文に出てくる語を重く数えます。「場合」「方法」「ファイル」のようなどの本にも出てくる語、タイトル・サブタイトル・著者名と同じ語（KDP では既にメタデータに含まれるため）、既に選んだ語の一部になっている語は除きます。短い一般的な語より、長く具体的な語を優先します。

形態素解析は使っていないので、語の区切りがおかしいものや、本の内容をよく表していない語が混じることがあります。「その他の候補」と見比べて入れ替えてください。

### カテゴリー

スクリプトの中の表（`CATEGORY_RULES`）にある分類ごとに、手がかりになる語がタイトル・説明文・キーワード・原稿に何回出てくるかを数え、点数の高い順に 3 つを候補にします。`book.yaml` に `kdp.categories` があれば、それを先に入れます。

カテゴリーの名前は Amazon.co.jp の Kindle ストアの分類をもとにした**目安**です。KDP の選択画面に同じ名前・階層があるとは限りません。KDP の画面で、表示された候補の中から一番近いものを選んでください。

## book.yaml で内容を指定する（kdp セクション）

下書きの一部を自分で書いた内容に固定したいときは、`book.yaml` に `kdp:` セクションを書きます。どれも省略できます。

```yaml
kdp:
  description: >-               # 内容紹介の書き出し（省略すると description）
    毎日の繰り返し作業を、短いスクリプトで少しずつ自動化していくための本です。
  intro: ""                     # 書き出しの後に入れる文。省略すると「はじめに」の冒頭から作る。"" で入れない
  intro_length: 300             # 「はじめに」から取る文字数の上限
  toc_sections: true            # 「本書の内容」に節の見出しも入れる
  closing: >-                   # 内容紹介の最後に入れる文（省略可）
    プログラミングがはじめての方にもおすすめです。
  keywords:                     # キーワードを固定する（7 つまで。書くと原稿からは選ばない）
    - 業務効率化
    - Python 入門
    - 自動化
  categories:                   # カテゴリーを固定する（3 つまで）
    - ビジネス・経済 > 仕事術・整理術
```

`kdp.description` と `description` を分けておくと、EPUB のメタデータには短い説明、KDP の内容紹介には長めの紹介文、と使い分けられます。

## KDP の制限とチェックの内容

| 項目 | 制限・ルール | このスクリプトでの扱い |
|---|---|---|
| 内容紹介の長さ | **4,000 文字まで。HTML タグも文字数に含む**（例: `test` は 4 文字、`<b>test</b>` は 11 文字） | HTML 版の文字数を数え、超える場合は目次を省いて収める |
| 内容紹介の HTML | 改行・段落・太字・斜体・下線・見出し（大・中・小）・番号付きリスト・箇条書きが使える。見出しやリストは開始タグと終了タグの両方が必要 | `<p>` `<h4>` `<ul>` `<li>` `<br>` だけを使う。`kdp.description` などに書いたタグがこの範囲外なら警告（使えるタグ: `br` `p` `b` `strong` `i` `em` `u` `h4` `h5` `h6` `ol` `ul` `li`） |
| 内容紹介の記号 | `<` `>` `&` はタグと区別するため HTML エンティティにする | 自動で置き換える |
| 見えない文字 | ゼロ幅スペースなどの見えない文字があるとエラーになる（ワープロなどからコピーしたときに起きやすい） | 見つけたら警告 |
| 内容紹介に書けないもの | 電話番号・住所・メールアドレス・URL、レビュー・推薦文、広告・宣伝、時期によって変わる情報、在庫・価格・ほかの購入方法、ネタバレ、キーワードの羅列 など | 機械的に見つけられるもの（URL・メールアドレス・電話番号・価格・「無料」「期間限定」などの宣伝・「ベストセラー」などの順位・「新刊」などの時期・「レビュー」「絶賛」など）を警告 |
| キーワードの数 | **7 つまで**。1 つの欄に短いフレーズを入れてもよい | 7 欄の表にする。`kdp.keywords` が 8 個以上なら警告 |
| キーワードの長さ | 入力欄の文字数の上限がある | **1 欄 50 文字**を上限として確認（下の注記を参照） |
| キーワードに入れないもの | ほかの著者名・ほかの作品名、本の内容と関係のない語、タイトル・著者名などメタデータに既にある情報、主観的な評価（「最高の」など）、時期によって変わる語（「新刊」など）、宣伝の語（「無料」など）、Amazon のプログラム名、HTML タグ | タイトル・サブタイトル・著者名と同じ語は選ばず、`kdp.keywords` にあれば警告。宣伝・時期・HTML タグも警告 |
| カテゴリーの数 | **3 つまで**（電子書籍・ペーパーバックなど形態ごとに選ぶ） | 3 つまで候補を出す。`kdp.categories` が 4 個以上なら警告 |

確認しているのは、機械的に見つけられるものだけです。「本の内容と関係があるか」「ネタバレになっていないか」「ほかの著者名ではないか」などは、必ず自分で確かめてください。

### 根拠にした KDP ヘルプ

- [本の内容紹介の入力](https://kdp.amazon.co.jp/ja_JP/help/topic/G201189630)（4,000 文字・HTML タグを含めて数える・使えるタグ）
- [本の内容紹介のエラーまたは書式設定の修正](https://kdp.amazon.co.jp/ja_JP/help/topic/GC4VASCGNQP6LQ7L)（見えない文字によるエラー）
- [キーワードを利用して本を見つけやすくする](https://kdp.amazon.co.jp/ja_JP/help/topic/G201298500)（最大 7 つ・入れてはいけない語）
- [本のメタデータのガイドライン](https://kdp.amazon.co.jp/ja_JP/help/topic/G201097560)（内容紹介・キーワードに書けないもの）
- [KDP カテゴリー](https://kdp.amazon.co.jp/ja_JP/help/topic/G200652170)（3 つまで選べる）

> **注記:** このスクリプトを作成した環境からは kdp.amazon.co.jp・kdp.amazon.com に直接接続できなかったため、上の値は KDP ヘルプの検索結果に表示された内容をもとにしています。キーワードの「1 欄 50 文字」はヘルプに数値の記載がなく（「入力欄の文字数制限に注意」とだけある）、KDP の入力欄の仕様として広く知られている値です。KDP の画面で入力できる文字数が違う場合は、`book.yaml` の `kdp.keyword_max` で変えられます（同様に `kdp.description_max` で内容紹介の上限も変えられます）。出版前に上のヘルプで最新の内容を確認してください。

## KDP への入力

1. `python3 scripts/kdp-listing.py books/my-book` を実行し、`dist/my-book-kdp-listing.md` を開く
2. 「確認が必要なこと」があれば、`book.yaml` や原稿を直して実行し直す（または出力を直接直す）
3. 内容紹介・キーワード・カテゴリーを読み直し、手直しする
4. KDP の本棚で本の「電子書籍の詳細」（または「ペーパーバックの詳細」）を開く
   - **内容紹介**: HTML 版をコピーして貼り付ける。プレビューで改行や箇条書きが崩れていないか確かめる
   - **キーワード**: 表の 1〜7 を 1 欄ずつ入力する
   - **カテゴリー**: 「カテゴリーを選択」から、候補に近い分類を探して 3 つまで選ぶ
5. 内容紹介とキーワードは出版後も何度でも変えられます。Amazon で実際に検索して、結果が本と合わない語は入れ替えてください。電子書籍とペーパーバックで同じ内容にしておくと、商品ページの印象がそろいます

## カテゴリーの候補を増やす

カテゴリーの候補は、`scripts/kdp-listing.py` の `CATEGORY_RULES` に「分類の名前」と「手がかりになる語」の組で書かれています。本の分野が表になければ、行を足してください。

```python
CATEGORY_RULES: list[tuple[str, list[str]]] = [
    # ...
    ("趣味・実用 > 園芸・ガーデニング",
     ["園芸", "ガーデニング", "家庭菜園", "植物", "観葉植物"]),
]
```

英数字だけの語（`Python` など）は単語の区切りで、それ以外は文字列として数えます。タイトル・説明文・キーワードに出てくる語は、原稿に出てくる語より重く数えます。
