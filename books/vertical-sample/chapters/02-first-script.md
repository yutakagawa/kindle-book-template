## ファイルを一括でリネームする

最初の題材は、フォルダの中のファイル名を一括で変える作業です。
[@lst:rename]は、写真のファイル名を撮影日の順に{整|ととの}えるスクリプトです。

```{.python #lst:rename caption="写真のファイル名を連番にする"}
from pathlib import Path

folder = Path("photos")
files = sorted(folder.glob("*.jpg"))

for i, path in enumerate(files, start=1):
    new_name = f"{i:03d}.jpg"   # 001.jpg, 002.jpg ...
    path.rename(folder / new_name)
    print(f"{path.name} -> {new_name}")
```

保存したら、ターミナルで次のように実行します。

```bash
python3 rename.py
```

::: warning
ファイル名の変更は元に戻せません。
はじめて試すときは、必ずフォルダのコピーで実行してください。
:::

## 結果を確かめる

実行すると、画面に変更前と変更後のファイル名が表示されます[^print]。
思ったとおりの名前になっていれば成功です。

[^print]: `print` は画面に文字を表示する関数です。動作を確かめるために、途中経過を表示させておくと安心です。
