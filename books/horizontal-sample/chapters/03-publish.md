# KDPで出版する {#sec:publish}

## アップロードの流れ

1. KDP（<https://kdp.amazon.co.jp/>）にサインインし、「電子書籍」を新規作成します。
2. 「電子書籍の詳細」で、タイトル・著者・内容紹介・キーワードなどを入力します。
3. 「電子書籍のコンテンツ」で、生成したEPUBと表紙画像をアップロードします。
4. オンラインプレビューアーで表示を確認します。
5. 「価格設定」で、ロイヤリティと価格を決めて出版します。

::: caution
タイトルや著者名は、`book.yaml` とKDPの入力欄で同じにしてください。
食い違いがあると、審査で修正を求められることがあります。
:::

## ISBNについて

KDPで電子書籍を出版する場合、ISBNは必要ありません。
Amazonが自動でASIN（Amazon標準識別番号）を割り当てます。
このテンプレートでは、ISBNがない場合はUUIDを識別子に使います。

## 表紙について

表紙画像はEPUBに埋め込むだけでなく、KDPの画面でも別途アップロードします。
KDPの推奨サイズは高さ2,560×幅1,600ピクセル（縦横比1.6:1）です。

::: {.tip title="表紙のチェックポイント"}
- タイトルと著者名が、サムネイル（小さい表示）でも読めるか
- 解像度が足りずにぼやけていないか
- 白い背景の場合は、境界がわかるよう枠線を付けたか
:::
