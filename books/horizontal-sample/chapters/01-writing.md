# 原稿の書き方 {#sec:writing}

この章では、本テンプレートで使えるMarkdownの記法を、実際の表示例とともに紹介します。
原稿は章ごとに1つのファイルへ分け、`book.yaml` の `chapters` の並び順で1冊にまとめられます。

## 見出し

`#` が章タイトル（1ファイルに1つ）、`##` が節、`###` が項です。
章タイトルには自動で「第1章」のような番号が付き、目次も自動で生成されます。

```markdown
# 原稿の書き方 {#sec:writing}

## 見出し

### 小見出し
```

`{#sec:writing}` は参照用のIDです。本文中で `@sec:writing` と書くと、
「[@sec:writing]」のように章番号へのリンクになります。

### 小見出し（項）

目次には `toc_depth` で指定した深さまでの見出しが載ります（既定は節まで）。

## 段落と強調

段落は空行で区切ります。日本語の文中で改行しても、余計な空白は入りません。
このように
途中で改行しても
1つの段落としてつながります。

**太字**、*斜体*、`インラインコード`、[リンク](https://kdp.amazon.co.jp/)が使えます。

## コードブロック

コードブロックは言語名を付けるとシンタックスハイライトされます。
Kindleの白黒端末（E-ink）でも区別できるよう、キーワードは太字、コメントは斜体にしています。

```python
def greet(name: str) -> str:
    """あいさつ文を返す"""
    # f文字列で埋め込む
    return f"こんにちは、{name}さん！"

for n in ["Kindle", "KDP"]:
    print(greet(n))
```

`caption` を付けると「リスト」番号付きのキャプションになり、`#lst:` のIDで参照できます。

```{.javascript #lst:fetch caption="APIからデータを取得する"}
async function fetchBooks() {
  const res = await fetch("https://api.example.com/books");
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return res.json();
}
```

[@lst:fetch]のように、Kindleは横スクロールができないため、長い行は自動的に折り返して表示されます。
それでも読みやすさのために、1行はおおむね60文字以内に収めるのがおすすめです。

## 表

表はパイプ記法で書きます。表の直後に `: キャプション {#tbl:ID}` を書くと番号が付きます。

| 記法             | 用途                 | 例                  |
|:-----------------|:---------------------|:--------------------|
| `#`              | 章タイトル           | `# はじめに`        |
| `##`             | 節見出し             | `## インストール`   |
| `**…**`          | 太字                 | `**重要**`          |
| `[^1]`           | 脚注                 | `本文[^1]`          |
| `[漢字]{ruby="かんじ"}` | ルビ           | [漢字]{ruby="かんじ"} |

: 主なMarkdown記法 {#tbl:syntax}

ルビの短縮記法 `{漢字|かんじ}` は `|` を含むため、表の中ではspan記法を使います。
[@tbl:syntax]のように、表は小さな画面でも収まるよう、列は3〜4列程度に抑えましょう。
大きな表は画像にするか、複数の表に分けると読みやすくなります。

## 画像と図番号

画像は `images/` に置き、`![キャプション](パス){#fig:ID}` と書きます。
キャプションがある画像には自動で図番号が付きます（[@fig:flow]）。

![原稿からEPUBができるまで](images/build-flow.png){#fig:flow}

## 囲み（注意書き・コラム）

`:::` で囲むと、注意書きなどの囲みになります。

::: note
これは「メモ」の囲みです。補足情報を書くのに使います。
:::

::: tip
これは「ヒント」の囲みです。`::: tip` と書きます。
:::

::: warning
これは「注意」の囲みです。読者が失敗しやすい点を書きます。
:::

::: {.column title="コラム：見出しは自由に変えられる"}
`title` 属性で見出しを変えられます。種類は note / tip / important / warning / caution / column の6つです。
:::

## 脚注

本文中に `[^名前]` と書き、別の場所に `[^名前]: 内容` と書くと脚注になります[^footnote]。
Kindleでは、脚注番号をタップするとポップアップで表示されます[^popup]。

[^footnote]: これが脚注の内容です。
[^popup]: EPUB3の `epub:type="noteref"` と `epub:type="footnote"` が付与されるため、Kindleのポップアップ脚注に対応します。

## ルビ

`{漢字|かんじ}` と書くとルビ（ふりがな）が付きます。
例：{薔薇|ばら}、{紫陽花|あじさい}、{東京|とう|きょう}（1文字ずつ読みを付けるモノルビ）。

Pandocのspan記法 `[漢字]{ruby="かんじ"}` でも書けます：[憂鬱]{ruby="ゆううつ"}。
