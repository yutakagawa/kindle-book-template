# 原稿を書く {#sec:writing}

この章では、原稿に使えるMarkdownの記法を紹介します。
原稿はPandocのMarkdownで、一般的なMarkdownに、図表の番号・囲み・ルビなどの記法を足したものです。

## ファイルの分け方

原稿は**1章を1ファイル**に分けて書きます。
ファイル名に `01-overview.md` のような番号を付けると、順番がわかりやすくなります。
章ごとにEPUBの中のファイルが分かれ、各章は新しいページから始まります。

## 見出しと章番号

`#` が章、`##` が節、`###` が項です。章の見出しは1ファイルに1つだけ書きます。

```markdown
# はじめに {.unnumbered}       ← 番号なしの章
# 原稿を書く {#sec:writing}    ← 「第3章 原稿を書く」になる
## 見出しと章番号              ← 節
### 項の見出し                 ← 項
# 記法早見表 {.appendix}       ← 「付録A 記法早見表」になる
```

`{#sec:writing}` は参照用のIDです。本文に `[@sec:writing]` と書くと、
「[@sec:writing]」のように章番号へのリンクになります。

### 項の見出し

この見出しが項です。目次には `toc_depth` で決めた深さまでの見出しが載ります。
本書は `toc_depth: 2` なので、目次に載るのは節までです。

## 段落と強調

段落は空行で区切ります。日本語の文の途中で改行しても、余計な空白は入りません。
この段落も、
原稿では3行に
分けて書いています。

**太字**、*斜体*、`インラインコード`、[リンク](https://kdp.amazon.co.jp/)が使えます。
箇条書きは `-`、番号付きの箇条書きは `1.` で書きます。

1. 原稿を書く
2. チェックする
   - 表記ゆれ
   - リンク切れ
3. ビルドする

> 引用は行頭に `>` を付けます。ほかの文献から文章を引くときに使います。

## コードブロック

コードブロックに言語名を付けると、シンタックスハイライトされます。
白黒の端末でも区別できるよう、キーワードは太字、コメントは斜体で表示されます。

```python
from pathlib import Path

def count_chars(path: Path) -> int:
    """原稿の文字数を数える（空白と改行は除く）"""
    text = path.read_text(encoding="utf-8")
    return sum(1 for ch in text if not ch.isspace())

for md in sorted(Path("chapters").glob("*.md")):
    print(f"{md.name}: {count_chars(md)}文字")
```

`caption` を付けると番号付きのキャプションになり、`#lst:` のIDで参照できます。
[@lst:fence]は、キャプション付きのコードブロックの書き方です。

````{.markdown #lst:fence caption="キャプション付きのコードブロックを書く"}
```{.javascript #lst:fetch caption="APIからデータを取得する"}
const res = await fetch(url);
```
````

Kindleは横にスクロールできないため、長い行は折り返して表示されます。
読みやすさのために、**1行は60文字程度まで**にしましょう。

## 表

表はパイプ記法で書き、直後に `: キャプション {#tbl:ID}` を書くと番号が付きます。
列の揃えは、区切り行の `:` の位置で決まります（[@tbl:align]）。

| 区切り行の書き方 | 揃え   | 向いている内容       |
|:-----------------|:------:|---------------------:|
| `:---`           | 左     | 文章・名前           |
| `:---:`          | 中央   | 記号（○ / –）        |
| `---:`           | 右     | 数値（1,600px）      |

: 列の揃えの指定 {#tbl:align}

小さな画面でも収まるよう、列は3〜4列程度にします。
表の中で `|` を書くときは `\|` とエスケープします。

## 画像と図番号

画像は `images/` に置き、`![キャプション](パス){#fig:ID}` と書きます。
キャプションがある画像には、自動で図番号が付きます。
番号の付き方と参照の関係は[@fig:crossref]のとおりです。

![IDを付けて参照すると番号付きのリンクになる](images/fig-crossref.png){#fig:crossref}

図・表・リストの番号は章ごとに数え直されます。
章や図を並べ替えても、番号と参照は自動で振り直されます。
参照先のIDが見つからないときは、ビルドとチェックの両方で指摘されます。

## 囲み

`:::` で囲むと、注意書きなどの囲みになります。種類は6つです。

::: note
補足情報を書きます。`::: note` と書きます。
:::

::: tip
知っていると便利なことを書きます。`::: tip` と書きます。
:::

::: important
読み飛ばしてほしくないことを書きます。`::: important` と書きます。
:::

::: warning
読者が失敗しやすい点を書きます。`::: warning` と書きます。
:::

::: caution
データが消えるなど、取り返しのつかない操作の前に書きます。`::: caution` と書きます。
:::

::: {.column title="コラム：囲みの見出しを変える"}
`title` 属性で見出しを変えられます。
`::: {.column title="コラム：囲みの見出しを変える"}` のように書きます。
:::

::: {.note title=""}
`title=""` と書くと、見出しの無い囲みになります。
:::

## 脚注

本文に `[^名前]` と書き、別の場所に `[^名前]: 内容` と書くと脚注になります[^footnote]。
脚注は各章の末尾にまとめて出力されます[^popup]。

[^footnote]: これが脚注の内容です。名前には、英数字だけでなく日本語も使えます。
[^popup]: EPUB3の `epub:type="noteref"` と `epub:type="footnote"` が付くため、Kindleでは脚注番号をタップするとポップアップで表示されます。

## ルビ

`{漢字|かんじ}` と書くと、ルビ（ふりがな）が付きます。

グループルビは、{紫陽花|あじさい}や{蒲公英|たんぽぽ}のように、言葉全体に読みを付けます。
読みを `|` で区切ると、{東京|とう|きょう}や{横浜|よこ|はま}のように1文字ずつ読みを付けるモノルビになります。
Pandocのspan記法でも、[憂鬱]{ruby="ゆううつ"}のように書けます。

表の中では `|` が使えないため、span記法の `[漢字]{ruby="かんじ"}` を使います。

## 縦書きのための指定

縦書きの本では、2桁までの数字が自動で縦中横になります。
自動で判定されない箇所には、次の指定を使います（横書きの本では表示が変わりません）。

| 書き方             | 効果                           | 例                  |
|:-------------------|:-------------------------------|:--------------------|
| `[12]{.tcy}`       | 縦中横（横に並べて1文字分に）  | 第[12]{.tcy}章      |
| `[AI]{.upright}`   | 英字を1文字ずつ正立            | [AI]{.upright}      |
| `[ABC]{.sideways}` | 横倒し                         | [ABC]{.sideways}    |

: 縦書きのための指定 {#tbl:vertical}

本書を縦書きでビルドすると、[@tbl:vertical]の「例」の列の見え方を確かめられます。

```bash
python3 scripts/build.py books/guide-book --writing-mode vertical
```

## 改ページと揃え

`::: pagebreak` で改ページ、`::: center` と `::: right` で中央揃え・右揃えになります。
右揃えは、縦書きでは下揃えになります。

::: center
この行は中央揃えです。
:::

::: right
この行は右揃えです。
:::

この段落のすぐ後ろに `::: pagebreak` を置いて改ページしています。

::: pagebreak
:::

::: center
**ここから次のページです。**
:::

章の途中で改ページを入れるのは、扉や区切りのページを作るときだけにしましょう。
画面の大きさは端末ごとに違います。普段は改ページを入れず、文章を流れるままにしておきます。
