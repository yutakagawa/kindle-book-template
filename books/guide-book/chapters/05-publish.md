# 出版する {#sec:publish}

最後の章では、できたEPUBをKindle Previewerで確認し、KDPで電子書籍として出版します。
同じ原稿からペーパーバックの本文PDFを作り、紙の本として出版する方法も説明します。
全体の流れは[@fig:publish]のとおりです。

![電子書籍とペーパーバックの出版の流れ](images/fig-publish.png){#fig:publish}

## Kindle Previewerで確認する

Kindle Previewer[^previewer]は、Amazonが提供している確認用のアプリです。
KDPと同じ変換エンジンで、実際の端末に近い表示を確かめられます。

[^previewer]: Kindle PreviewerはWindowsとmacOSで使えます。KDPのヘルプページからダウンロードできます。

1. Kindle Previewerを起動し、`dist/guide-book.epub` を開く
2. 端末の種類（タブレット・スマートフォン・白黒の端末）を切り替えて表示を確認する
3. 目次・脚注のポップアップ・図版・コードの折り返しを確認する

確認するときの観点を[@tbl:preview]にまとめます。

| 確認すること     | 見るところ                                 |
|:-----------------|:-------------------------------------------|
| 目次             | メニューの目次から各章へ移動できるか       |
| 脚注             | 番号をタップするとポップアップで出るか     |
| 図版             | 白黒の端末でも線と文字が読めるか           |
| コード           | 長い行が折り返され、途中で切れていないか   |

: Kindle Previewerで確認すること {#tbl:preview}

::: tip
ダークモードでも確認しておきましょう。背景が黒くなっても図版が読めるよう、
このテンプレートは画像の透過を自動で白い背景に置き換えています。
:::

## KDPで電子書籍を出版する

KDPの本棚で「電子書籍」を作成し、次の順に入力します。

1. **詳細情報**：書名・副題・著者名を `book.yaml` と同じ表記で入力する
2. **コンテンツ**：「原稿」に `dist/guide-book.epub` をアップロードする
3. **表紙**：`dist/guide-book-cover.jpg` をアップロードする
4. **プレビュー**：オンラインのプレビューアーで表示を確認する
5. **価格設定**：ロイヤリティと価格を決めて出版する

::: important
KDPでは、表紙の書名・著者名が入力した書誌情報と一致している必要があります。
表紙は `book.yaml` の値から作られるので、KDPの入力欄も同じ表記にそろえてください。
:::

## ペーパーバックの本文PDFを作る

同じ原稿から、KDPペーパーバックの本文PDFを作れます。
組版には、CSSで組版するVivliostyleを使います。

```bash
npm install                                 # 初回だけ
make paperback-book BOOK=books/guide-book   # → dist/guide-book-paperback.pdf
```

判型や余白は、`book.yaml` の `paperback` で設定します（[@lst:paperback]）。

```{.yaml #lst:paperback caption="本書のペーパーバックの設定"}
paperback:
  trim: a5            # 判型（148×210mm）
  bleed: false        # 裁ち落としなし
  paper: white        # 用紙（背幅の計算に使う）
  font: serif         # 本文は明朝体
  font_size: 9.5pt
  line_height: 1.7
  colophon: true      # 巻末に奥付を入れる
```

### 判型を選ぶ

主な判型を[@tbl:trim]にまとめます。
A5とB6は、KDPでは「カスタムの判型」として幅と高さを入力します。

| `trim`   | 寸法               | 向いている本           |
|:---------|-------------------:|:-----------------------|
| `a5`     | 148 × 210mm        | 技術書・実用書         |
| `b6`     | 128 × 182mm        | 読み物・エッセイ       |
| `5x8`    | 5 × 8インチ        | 小説                   |
| `6x9`    | 6 × 9インチ        | 洋書の技術書           |

: 主な判型 {#tbl:trim}

### ノドの余白は自動で決まる

KDPでは、ページ数が多いほど内側の余白（ノド）を広く取る必要があります。
ページ数は組んでみないとわからないため、ビルドスクリプトが
**組版 → ページ数を数える → 足りなければノドを広げて組み直す**を自動で行います。

| ページ数        | ノドの最小値           |
|:----------------|-----------------------:|
| 24〜150         | 0.375インチ（9.5mm）   |
| 151〜300        | 0.5インチ（12.7mm）    |
| 301〜500        | 0.625インチ（15.9mm）  |

: ページ数とノドの最小値 {#tbl:gutter}

ビルドが終わると、PDFのページ数と、表紙PDFを作るときの寸法（背幅を含む）が表示されます。
紙の本の表紙は、表1（表紙）・背・表4（裏表紙）を1枚にしたPDFとして別に作ります。

::: warning
KDPの要件は変わることがあります。出版する前に、KDPのヘルプと印刷プレビューアーで
余白・ノド・裁ち落としの警告が無いことを確認し、校正刷りで実物を確かめてください。
:::

## 出版したあとに直す

誤字を見つけたら、原稿を直して再ビルドし、KDPに同じ本としてアップロードし直します。
`uuid` を変えずにおけば、同じ本の新しい版として扱えます。

```bash
npm run lint -- books/guide-book && make check
```

原稿をGitで管理していれば、どの版で何を直したかも後から確認できます。
